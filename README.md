# Dependency Visualizer

CLI-инструмент визуализации графа зависимостей пакетов NuGet.

Получение зависимостей реализуется самостоятельно, без использования
менеджеров пакетов и сторонних библиотек для получения зависимостей.

## Требования

Python 3.11 или новее.

Для запуска приложения сторонние библиотеки не требуются.

## Структура проекта

- src/main.py — точка входа приложения.
- src/config.py — чтение и проверка конфигурации.
- src/nuget.py — получение прямых зависимостей NuGet.
- tests/ — папка для тестов.
- config.toml — конфигурация приложения.
- run.bat — скрипт запуска для Windows.
- run.sh — скрипт запуска для Linux и macOS.

## Конфигурация

Настройки задаются в файле config.toml:

```toml
package_name = "Newtonsoft.Json"
repository = "https://api.nuget.org/v3/index.json"
test_mode = false
ascii_tree = true
```

Параметры:

- package_name — имя анализируемого пакета NuGet.
- repository — URL индекса NuGet или путь к тестовому репозиторию.
- test_mode — режим работы с тестовым репозиторием.
- ascii_tree — режим вывода зависимостей в виде ASCII-дерева.

Относительный путь к тестовому репозиторию считается от папки
конфигурационного файла.

## Запуск

Выполняйте команды из корня проекта.

Запуск с конфигурацией по умолчанию:

```shell
python src/main.py
```

Запуск с другим конфигурационным файлом:

```shell
python src/main.py --config custom.toml
```

Запуск через скрипт в Windows PowerShell:

```powershell
.\run.bat
```

Запуск через скрипт в Linux и macOS:

```shell
sh run.sh
```

## Этап 1. Конфигурация

Реализованы:

- чтение настроек из TOML;
- проверка наличия, типов и значений обязательных параметров;
- обработка ошибок чтения файла и синтаксиса TOML;
- вывод настроек в формате ключ-значение.

## Этап 2. Получение прямых зависимостей

Реализованы:

- получение адреса сервиса метаданных из индекса NuGet;
- загрузка метаданных пакета через HTTP;
- выбор последней опубликованной стабильной версии;
- извлечение прямых зависимостей по всем целевым платформам;
- вывод имени зависимости, диапазона версий и платформы;
- обработка сетевых ошибок, ошибок HTTP и некорректных ответов.
